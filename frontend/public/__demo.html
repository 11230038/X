解题步骤：

1. 观察式子，当 x→0 时，分子分母均趋于 0。

2. 使用泰勒展开：
ln(1+x) ≈ x - x²/2 + x³/3 - ...

3. 代入分子化简得到 x³/3。

4. 原式 = (x³/3) / x³ = 1/3。

为什么范围查询能用上索引，而函数包裹的列不能？
索引是一棵按列值排好序的树。范围查询能利用这个顺序，从起点顺着叶子链表读下去；而 WHERE DATE(created_at) = ... 改变了参与比较的值，优化器无法把函数结果映射回索引上的有序位置，只能逐行计算，于是退化成全表扫描。

想让这类查询走索引，要么改写成对列本身的范围条件（created_at >= ... AND created_at < ...），要么建立函数索引或生成列。

2.2 B+ 树索引

来源：《数据库系统概念》 · 1,240 字

B+ 树是关系型数据库中最常用的索引结构。与二叉搜索树不同，B+ 树是一种多路搜索树，它的每个节点可以包含多个键值和多个子节点，从而极大地降低了树的高度，减少了磁盘 I/O 的次数。

在 B+ 树中，所有的数据记录都存储在叶子节点上，并且叶子节点之间通过指针相互连接，形成了一个有序链表。这个特性使得 B+ 树不仅支持高效的等值查询，还极其适合范围查询。
